Widget demo

This page stands in for a customer's site. The chat button should appear in a corner.

Try it

  1. Edit the snippet at the bottom of this file: set src to your app URL + /widget.js (for example http://localhost:3000/widget.js) and data-key to a dev pk_… key.
  2. Serve this folder from a different origin than the app: python3 -m http.server 8080 (run it in apps/widget/demo), then open http://localhost:8080.
  3. Click the button. The panel opens; send a message and you get a mock reply. Close it with the ✕ or Escape.

Which app to point at

Use the app running locally (pnpm dev, then http://localhost:3000) or an unprotected deployment. This page is on another origin than the app, which is the point of the demo.

Protected Vercel previews do not work from this page. The widget loads its config with a cross-origin fetch that sends no cookies, and Deployment Protection blocks every request without authentication, so the config fetch fails and nothing renders. Visiting the preview first with ?x-vercel-protection-bypass=<secret>&x-vercel-set-bypass-cookie=samesitenone sets a cookie that only the iframe can use, not the fetch. Never commit the secret.

The snippet

<script src="https://YOUR-APP.vercel.app/widget.js" data-key="pk_YOUR_KEY" async></script>
