Widget demo

This page stands in for a customer's site. The chat button should appear in a corner.

Try it

  1. Edit the snippet at the bottom of this file: set src to your app URL + /widget.js and data-key to a dev pk_… key.
  2. Serve this folder from a different origin than the app: python3 -m http.server 8080 (run it in apps/widget/demo), then open http://localhost:8080.
  3. Click the button. The panel opens; send a message and you get a mock reply. Close it with the ✕ or Escape.

Protected Vercel preview

Previews are behind Vercel's login. Load this page once with http://localhost:8080/?x-vercel-protection-bypass=<secret>&x-vercel-set-bypass-cookie=samesitenone so the iframe gets the bypass cookie across sites. Never commit the secret.

<script src="https://YOUR-APP.vercel.app/widget.js" data-key="pk_YOUR_KEY" async></script>
